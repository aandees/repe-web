Conectar Repe a una IA

Repe tiene un servidor MCP (Model Context Protocol, el estándar para conectar datos a una IA): cualquier asistente compatible puede leer tus entrenos, récords y medidas para analizar tu progreso y, si se lo permites, crearte rutinas o apuntar medidas.

Dirección del servidor:

https://vazvpvtxljbjyhtmrglo.supabase.co/functions/v1/api/mcp
Solo da acceso a tus datos y con los permisos que elijas. Lo que la IA lea se envía a su proveedor (OpenAI, Anthropic…). Puedes quitar la conexión cuando quieras en la app: Ajustes → Cuenta → Conexiones y API.

ChatGPT

  1. En ChatGPT (web), abre Ajustes → Aplicaciones y conectores → Ajustes avanzados y activa el modo desarrollador.
  2. Vuelve a Aplicaciones y conectores y pulsa Crear.
  3. Nombre: Repe. URL del servidor MCP: la de arriba. Autenticación: OAuth.
  4. Se abrirá la página de Repe: entra con tu email o usuario y elige qué puede hacer ChatGPT.
  5. En un chat nuevo, activa Repe en el menú + y pregunta, por ejemplo: «¿Cómo ha ido mi semana de entreno?».

Claude (claude.ai y la app móvil)

  1. En claude.ai, abre Ajustes → Conectores → Añadir conector personalizado.
  2. Nombre: Repe. URL: la de arriba.
  3. Pulsa Conectar, entra con tu cuenta de Repe y elige los permisos. El conector también aparecerá en la app de Claude del móvil.

Claude Code y Cursor

También inician sesión con tu cuenta de Repe, sin claves:

  • Claude Code: claude mcp add --transport http repe https://vazvpvtxljbjyhtmrglo.supabase.co/functions/v1/api/mcp y, dentro de Claude Code, /mcp → Repe → Autenticar.
  • Cursor: en mcp.json, { "mcpServers": { "repe": { "url": "https://vazvpvtxljbjyhtmrglo.supabase.co/functions/v1/api/mcp" } } } y pulsa Conectar en los ajustes de MCP.

Claude Desktop usa los mismos conectores que claude.ai: si ya lo has añadido allí, aparece solo.

Claves personales (avanzado)

Para programas que no pueden iniciar sesión (scripts, Atajos de iOS, automatizaciones) hay claves personales: en la app, Ajustes → Cuenta → Conexiones y API → Nueva clave. Al crearla puedes copiar la configuración para Claude Desktop, Claude Code o Cursor con la clave dentro. Si tu asistente permite iniciar sesión, no necesitas ninguna.

Otros asistentes

Funciona con cualquier asistente o programa que admita servidores MCP remotos con inicio de sesión OAuth (por ejemplo VS Code con Copilot, Gemini CLI, Windsurf o Le Chat de Mistral): añade un servidor o conector MCP con la dirección de arriba y, cuando lo pida, entra con tu cuenta de Repe.

Qué puede hacer

  • Leer: resumen del periodo, entrenos, progreso de cada ejercicio (y si está estancado), equilibrio muscular, rutinas, récords y medidas.
  • Crear rutinas y apuntar medidas (si lo permites): las rutinas nuevas van a la carpeta «Sugerencias» para que las revises.
  • Registrar, corregir o borrar entrenos (si lo permites): calcula volumen y récords como la app. Los registrados son privados por defecto.

Para programadores

También hay una API REST con la misma clave. Documentación OpenAPI: https://vazvpvtxljbjyhtmrglo.supabase.co/functions/v1/api/v1/openapi.json.
